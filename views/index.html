Google Business Profile

OAuth 2.0 Authentication

This application demonstrates OAuth 2.0 authentication flow with the Google Business Profile API. Click the button below to securely log in with your Google account.

Features

  • OAuth 2.0 Authorization Code Flow
  • Secure Token Management
  • Automatic Token Refresh
  • Business Account Management

API Endpoints

/accounts - List business accounts

/locations - Get business locations

/reviews - Fetch customer reviews

ℹ️ Note: Make sure you have configured the OAuth credentials in your .env file with GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, and GOOGLE_REDIRECT_URI.
